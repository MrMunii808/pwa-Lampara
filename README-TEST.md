# Prueba rápida

1. Abrí la PWA con el ESP32 encendido.
2. Esperá hasta que aparezca `ESP32 conectado`.
3. Mirá que `Última actualización` cambie aproximadamente cada 10 s.
4. Cambiá la lámpara desde la PWA.
5. El ESP32 debe recibir el comando y marcarlo como ejecutado.
6. Si Realtime no está habilitado, la PWA usará el fallback REST de 15 s.
7. Si la PWA anterior queda instalada, primero probá la URL normal con `Ctrl + Shift + R`.
